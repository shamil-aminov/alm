# A title can live in the body

This post has no title in its frontmatter: its first line names it. That is
easier to write — the file reads as text rather than as a table of settings —
and the page still gets a title, an excerpt and a name in the feed.

What does not happen: the title is not shown twice. The page knows the body
already opens with the name, and draws none of its own above it.
